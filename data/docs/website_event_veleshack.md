# 🚀 VelesHack

## Riding the Edge-to-Cloud Continuum
📅 6–8 October 2026
📍 Universitat Politècnica de València (UPV), Valencia, Spain

VelesHack: Riding the Edge-to-Cloud Continuum brings together students, developers, researchers, and tech innovators for a two-day coding sprint exploring the future of AI-powered, decentralised systems, followed by a final day of pitches and awards.
This is your playground to experiment, co-create, and tackle real-world challenges using cutting-edge technologies developed by four Horizon Europe projects: HYPER-AI, CoGNETs, ENACT, and O-CEI.
Bring your best ideas, team up, compete for exciting prizes, and get the chance to showcase your work to leading European researchers and technology pioneers.

## ⚡ Choose Your Challenge

### Challenge 1: Hyperion – An LLM-Powered Agentic Assistant
Building an Agentic Assistant for the HYPER-AI IDE
Develop Hyperion, an agentic microservice that allows users to interact with the HYPER-AI IDE through natural language. The assistant will use an LLM to answer questions about HYPER-AI, control the IDE frontend, create, edit, and delete files, and act on the user’s behalf.
What you will learn: conversational AI agents, RAG, streamed Server-Sent Events (SSE), and session memory.
Skills to bring: Python, Docker, and a basic understanding of LLM APIs or agentic frameworks.

### Challenge 2: Trust Ledger Traceability
Improved Traceability of Trust Information with Eclipse aeriOS and IOTA Tangle
Design a mechanism, such as a dashboard, to inspect which messages have been inserted into the aeriOS IOTA Tangle. Your solution should be able to search for specific messages on demand and clearly present the results.
What you will learn: auditing transaction streams on the IOTA Tangle and securing distributed data through encryption.
Skills to bring: software development, Git, APIs, and a basic understanding of blockchain or Distributed Ledger Technologies.

### Challenge 3: Kubernetes Dynamic Adaptation
Application Development and Runtime Performance Adaptation in the ENACT CCC
Explore how runtime policies can influence application performance in distributed environments. Participants will work with ENACT mechanisms for defining the desired runtime state of applications and experience how workloads can adapt dynamically across Kubernetes infrastructures.
What you will learn: deploying distributed applications to live Kubernetes clusters and configuring runtime policies to optimise performance.
Skills to bring: Git, Kubernetes/Helm, Java, Python or Go, and Eclipse IDE.

### Challenge 4: Smart Edge Resource Auctions
Dynamic Node Registration and Resource Allocation in an Edge Computing Environment
Explore how dynamic device discovery and game-theory-inspired auction mechanisms can support self-organising Edge and IoT systems. Participants will build smart Edge agents capable of competing for resources under realistic constraints.
What you will learn: game-theory-inspired bidding algorithms and dynamic, decentralised resource scheduling.
Skills to bring: Python, Docker, REST APIs, JSON handling, and basic algorithmic logic.
