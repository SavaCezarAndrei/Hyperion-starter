- Cognitive Computing Continuum Cluster

            Co-creating technologies and tools for the cognitive computing continuum
Seven Horizon-funded projects have joined efforts in the Cognitive Computing Continuum Cluster to promote the use of the Cloud-Edge Continuum as a secure, autonomous, reliable, and self-managing computing resource.

            The Cognitive Computing Continuum Cluster, comprising Horizon Europe projects HYPER-AI, INTEND, EMPYREAN, ENACT, MYRTUS, Swarmchestrate, and CoGNETs, aims to enhance seamless data and service management across the Cloud-Edge Continuum. These projects focus on innovative techniques for managing computing resources from IoT and edge devices to central cloud centres, utilising Swarm computing and AI for automation and dynamic resource allocation. The cluster emphasises energy-efficient and trustworthy data processing at the edge, integrating intelligent orchestration mechanisms to handle vast data volumes and support scalability. Key areas include autonomous management, distributed machine learning, end-to-end security, and interoperability based on open standards, aligning with the European Partnership on AI, data, and robotics.
